# 安装、配置和停用

适用：Android 8.0 及以上。当前 0.1.4 为 debug 签名测试包，平板及其他厂商机型尚未实测。

## 下载与安装

从本项目 [v0.1.4 Releases](https://github.com/Rsfhg/focuslock/releases/tag/v0.1.4) 下载 `FocusLock-0.1.4-debug.apk`。不要下载来源不明的改包。附件 `SHA256SUMS.txt` 可以用于确认下载文件是否与本次附件一致，不证明软件没有安全问题。

先阅读 [权限和隐私说明](../PRIVACY.md)。是否安装及开启无障碍由你决定。系统可能提示来自外部来源、未审核或受限设置，请阅读提示；不接受这些风险时可以停止安装和使用。当前不提供官方认证或商店审核通过的承诺。

## 按需要配置

1. 开启“限时用”的无障碍服务，这是自动识别和拦截的核心条件。当前服务能力包含访问窗口内容，实际用途见隐私说明。
2. 按需要允许通知，用于本次使用剩余一分钟提醒；拒绝后没有系统通知提醒。
3. 按需要允许“闹钟和提醒”，提高后台提醒及到期检查的准时性；没有该授权时相关调度受限。
4. 根据机型配置自启动及后台运行。小米 HyperOS 实测中，“自启动已开”仍不能避免省电策略冻结进程：在限时用的应用信息/耗电或省电策略中选择“无限制”后改善。菜单名称以实际系统为准，后台运行也可能影响耗电，应自行观察。
5. 添加一个非重要应用，选择自由或冷却模式，填写单次上限。初次测试先申请 1 分钟，确认开始、到期和重新进入的行为符合预期。

无障碍显示已开启，不保证进程始终未被系统冻结。具体系统可能要求另外确认受限设置，请阅读系统风险说明，软件不应以隐藏这些提示作为正常步骤。

## 使用和更新

- 每次输入整数分钟，切换或锁屏不暂停计时。
- 自由模式到期后可重新申请；冷却模式需等待冷却结束。冷却从原定使用截止时刻开始。
- 使用或冷却期间，本应用内不能加时、改规则或移出该应用。
- 与原测试包签名相同时可以覆盖更新，保留原规则和会话。更新后建议关闭再开启一次本应用无障碍服务，再验证实际拦截。未来切换正式签名时可能不能直接覆盖，会另行说明。

## 遇到问题

先记录机型、Android/厂商系统版本、限时用版本、复现步骤；出现延迟或误拦截后，可打开限时用，点击“复制拦截诊断”。进程结束后记录会丢失。

检查诊断内容、删除不愿公开的包名等信息，再决定是否提交 [Issue](https://github.com/Rsfhg/focuslock/issues/new)。不要提供序列号、账号、聊天内容、付款信息等私人信息。

## 随时停用

在系统无障碍设置关闭“限时用”，即可停止其自动拦截；也可以从应用信息强行停止或卸载。清除应用数据或卸载会删除本地规则和会话，单独关闭无障碍不会删除这些数据。

本应用不阻止撤权和卸载，不强制终止目标应用后台播放或下载。分屏、小窗、画中画、分身、第二空间、重启改时钟和厂商后台清理等场景仍有边界，不能作为不可绕过的控制工具。
