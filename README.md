# 限时用 · FocusLock

**打开前决定用多久，到点结束。**

一个用于本人自律的 Android 应用。每次打开所选应用前，输入本次使用的整数分钟；计时持续进行，到期结束。可以为每个应用选择自由模式或冷却模式。

**当前为 0.1.4 测试版，仅适用于 Android 8.0 及以上。尚未验证平板和所有厂商系统，不是 iPhone/iPad 应用。**

[下载测试版 APK](https://github.com/Rsfhg/focuslock/releases/tag/v0.1.4) · [安装与停用](docs/INSTALL.md) · [权限和隐私说明](PRIVACY.md) · [反馈问题](https://github.com/Rsfhg/focuslock/issues/new)

## 怎么使用

1. 安装测试包，阅读权限说明，按需要开启无障碍服务、提醒和适合机型的后台设置。
2. 添加想限制的应用，设置单次时长上限和模式。
3. 打开受限应用，选择这次用几分钟。
4. 时间到后返回桌面。自由模式可以重新申请；冷却模式需要先等待冷却结束。

切换应用、锁屏不会暂停计时。已开始的使用或冷却期间，不能在本应用内加时、修改该应用规则或移出列表。

## 权限与信任

- 当前版本没有账号、服务器、广告或应用内自动上传功能，未声明 `INTERNET` 权限；规则和会话保存在设备本地。
- 无障碍服务用于识别前台应用、显示拦截界面及执行返回桌面。**当前配置允许获取窗口内容，属于需要认真考虑的敏感能力。** 当前实现使用窗口状态、包名等识别信息，不读取页面文字或输入内容；具体范围见 [PRIVACY.md](PRIVACY.md)。
- 通知用于提醒；精确闹钟辅助到期检查；部分手机还需要自启动或后台运行设置。这些用途和关闭后的影响见 [安装说明](docs/INSTALL.md)。
- 你可以从系统设置关闭无障碍、强行停止或卸载。软件不阻止这些操作，也不承诺防绕过。
- 当前下载包是 **debug 签名测试包**，可调试，尚未完成正式发布签名迁移、应用商店审核或独立安全审计。源码公开、校验值和签名均不代表官方安全认证。备案及各分发渠道要求仍需在正式发行前核实、办理适用手续。

## 当前限制

- 仅在一台 Redmi K70E / Android 16 / HyperOS 3.0.305.0 上完成部分真机验证；不同机型、系统更新和后台策略可能影响表现。
- 小米等系统可能冻结后台进程，即使无障碍显示已开启也可能延迟。相关设置和排查方法见安装说明。
- 首次进入仍可能有可见延迟，不能保证完全不出现目标应用画面。到期退出依赖系统事件及服务正常运行。
- 分屏、小窗、画中画、应用分身、第二空间和平板适配尚未验证。
- 不强制终止目标应用后台音频或下载；撤权、强停、清除数据、卸载等可以解除限制。
- 不应用于家长强制监控、企业设备管理或其他需要不可绕过保证的场景。

实测范围与方法限制见 [测试摘要](docs/TESTING.md)。

## 开发与核验

Kotlin、Compose、Room；应用包名 `com.local.focuslock`。开发环境：JDK 17+（开发时使用 21）、Gradle 8.13、Android Gradle Plugin 8.11.1、Kotlin 2.1.20、Android SDK 36 / Build Tools 35.0.0。

使用 Android Studio 打开仓库，安装相应 SDK，配置本机 `local.properties`，然后执行：

```sh
bash ./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Windows 使用 `gradlew.bat`。中文路径可运行 `./build.ps1 -SdkPath '你的 SDK 路径'`，脚本会建立临时英文路径链接。本机配置、构建缓存、签名密钥和手机原始诊断不在公开仓库中。

发布附件提供 APK 的 SHA-256 校验值。自行构建的 debug 签名依赖本机构建密钥，文件哈希未必相同；目前没有建立可复现构建验证，不能仅凭源码公开证明附件与源码一致。
